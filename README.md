# Super Lab Service — App Downloads

Downloads for Super Lab Service's digital records system. Get the latest version from the [Releases](../../releases) page.

## Installing

1. Download `LumaLabs-SuperLabService-portable.zip` and `scalyft-codesign.cer` from the latest release, below.
2. Double-click `scalyft-codesign.cer` → **Install Certificate** → **Local Machine** → **Trusted Root Certification Authorities** → Finish. (One-time, per computer.)
3. Extract the zip anywhere.
4. Right-click the program's `.exe` inside → **Send to** → **Desktop (create shortcut)**.
5. Open it from that shortcut.

No source code is published in this repository — it exists only to host downloadable builds.
